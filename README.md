# news-image-20261125 — Wednesday 25 November 2026 in one picture

A newspaper front page summing up Wednesday 25 November 2026 in one
1024×1024 image: 34 stories, all dated to that day (UTC) — 3 hero panels,
a UTC timeline, THE DAY IN NUMBERS, 10 panels, a pinned world map,
ALSO ON 14–34, and a DATE CHECK of stories left out on purpose.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
# writes /tmp/out/entry.png (1024x1024 PNG, under 1 MiB)
```

Sources: Reuters, AP, RFE/RL, Xinhua, Stars and Stripes, BBC, PINA,
Rivkin, First Feed News, IMCT News, Newsy Today, Speaks Media, Jagran Josh.
